## Mission

The owner's Columbia course, User Centric Design and Innovation, runs a semester team project. The team's earlier work (PawPal and PawPop, Weeks 2 to 5) drifted into "an app that does it all" for dog owners, which the professor rejected twice. On 2026-10-20 the owner restarted the project from scratch, keeping only the premise of dogs and pets.

Deliverables, in the owner's priority order:
1. **Fix the project.** Pick a real, evidenced problem, a specific customer, one primary service, an event that creates value before any network exists, and a clear account of how the person changes. Whimsy is welcome; the problem must be real.
2. **Week 6 assignment (Miro, 10 points, was due 2026-10-19):** an AI-made preliminary solution posted to Miro with the AI tools documented, plus a draft customer waveline (value map).
3. **Week 7 midterm (5 points, due 2026-10-20 at 6 pm per the owner):** at least 10 slides, a 7-minute talk on what was learned, how it changed the project, and how the owner will use the tools at work. Submitted as a file or a website URL.

## Sequence

1. Research: 8 parallel agents write `research/web/*` and `research/course/frameworks.md`.
2. Synthesis: read every report in full, then write `docs/concept-options.md` with the option space, the evidence for each option, and one recommendation with its strongest counterargument.
3. Owner decision on the direction (a decision sheet in plain words).
4. Week 6: build the AI-made prototype (the 3D website in this repo, made with Claude Code), draw the current-versus-ideal waveline, write the AI tool log, and export images the owner can paste into Miro.
5. Week 7: build the slide deck (10 or more slides) as a `.pptx` file generated by a JavaScript script, unless the owner picks another format.
